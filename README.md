# ECF - Vite & Gourmand

Application web réalisée dans le cadre de l'évaluation en cours de formation du titre professionnel Développeur Web et Web Mobile.

## Objectif du projet

L'application permet de consulter les menus d'une entreprise de traiteur, de créer un compte utilisateur, de commander un menu, de suivre une commande et de gérer les menus, commandes et avis depuis des espaces employé et administrateur.

## Stack technique prévue

- HTML
- CSS
- JavaScript
- PHP
- PDO
- MySQL / MariaDB
- Base NoSQL pour les statistiques
- Git / GitHub

## Installation locale

Les étapes d'installation seront ajoutées au fur et à mesure du développement.
